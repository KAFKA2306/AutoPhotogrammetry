# AutoPhotogrammetry — 画像収集・選別の研究プロトタイプ

**リポジトリ:** https://github.com/KAFKA2306/AutoPhotogrammetry

フォトグラメトリー用画像セットを作るために、Web画像の収集、画像特徴量の抽出、クラスタリング、生成画像の追加、品質指標による選別を試作したPythonプロジェクトです。

現在の実装は`main.py`へ複数の実験処理をまとめた初期プロトタイプです。完全な自動撮影、カメラ姿勢推定、COLMAP・Meshroomによる3D再構成、品質保証までを一貫して実行できる完成システムではありません。

## 現在コードに含まれる処理

- 指定URLのHTMLから画像URLを抽出
- キーワードを含む画像URLをダウンロード
- HOG、LBP、GLCM系の画像特徴量を計算
- DBSCANによる画像クラスタリング
- Stable Diffusion v1.4を使った画像生成の試作
- Laplacianなどを用いた画像品質評価の試作
- SSIMを使った画像比較処理

## 重要な制約

### フォトグラメトリーは「似た画像」では成立しない

3D再構成には、同じ実在対象を異なる視点から撮影し、表面特徴が幾何学的に対応している画像が必要です。生成AIで作った画像は形状・模様・照明が視点間で一貫しないことがあり、通常は実在物の正確なSfM/MVS入力として扱えません。

### Web画像の自動収集

現在の収集処理は一般的なHTMLの`img`タグを対象にした簡易実装です。

- robots.txtや利用規約を自動確認しません
- 著作権・ライセンスを自動判定しません
- 認証、JavaScript描画、レート制限へ対応しません
- Content-Typeやファイル破損の厳密な検証がありません
- 同一対象・同一撮影条件であることを保証しません

許諾のない画像をダウンロード・再配布・学習利用しないでください。

## 実用的なフォトグラメトリーへ進める手順

1. 自分で撮影できる対象物を選ぶ
2. カメラ設定、焦点距離、露出を固定する
3. 隣接画像で十分な重なりを確保する
4. 反射・透明・動く物体を避ける
5. ブレ、露出、被写界深度を検査する
6. COLMAPやAliceVisionで特徴点・カメラ姿勢を推定する
7. 再投影誤差と登録画像率を記録する
8. メッシュ完全性とテクスチャ品質を評価する
9. 失敗条件を残して撮影へフィードバックする
